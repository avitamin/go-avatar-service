# Specs

Этот каталог хранит спецификации целевого поведения и архитектурные change-specs.

## Что сюда класть

- базовые архитектурные спеки;
- change-specs с целевым состоянием, scope и acceptance criteria;
- документы, которые фиксируют поведение, а не порядок реализации.

## Что сюда не класть

- пошаговые implementation plans;
- rollout checklist;
- временные рабочие заметки.

- [02-health-runtime-checks.md](./02-health-runtime-checks.md) - change-spec по runtime checks для `/health`.
